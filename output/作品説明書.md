# 作品説明書 — Dungeon Survivor

## （1）ゲームの説明

『Dungeon Survivor』は、ダンジョンを探索し、敵を倒してキャラクターを強化しながら、最終ラウンドのボス撃破を目指すゲームです。

ステージは全4ラウンドで構成されています。通常ラウンドでは部屋や通路がランダムに配置され、ラウンドごとに背景や出現する敵が変化します。部屋の敵を倒し、宝箱から武器を獲得しながら先へ進みます。経験値によるレベルアップやラウンドクリア時には、強化を選択できます。

## （2）操作説明

**攻撃は自動です。**

|---|---|
| W・A・S・D | 移動する |
| 移動中にSpace | ダッシュで敵の攻撃をよける |
| Q | 時間を止める。停止中はダッシュで攻撃できる |
| F | 宝箱を開ける／使えるポータルで次へ進む |
| M | マップを開く・閉じる |
| Esc | 一時停止する・再開する |
| R | Restart | 

メニューでは**方向キー／W・A・S・Dで選び、Enterで決定**します。マウスの左クリックでも決定できます。

## （3）アピールポイント

### 1. 多彩な武器による爽快なバトル

周囲の敵を巻き込む火球、敵から敵へ連鎖する雷、敵を追いかける追尾弾など、攻撃方法の異なる多彩な武器が登場します。武器ごとに弾の動きやエフェクトが異なり、さまざまな攻撃で敵の群れを倒す爽快感を楽しめます。

### 2. ライティングを活かした華やかな演出

炎や雷などの光がダンジョンを照らし、ドット絵の世界に鮮やかな彩りを加えます。光を伴う攻撃エフェクトやダッシュの残像に、効果音と画面の揺れが重なり、迫力のある戦闘を演出します。

### 3. 時間を止めて敵を斬る特殊アクション

時間停止スキルを使うと、敵の動きが止まり、ダッシュが攻撃付きの強化ダッシュに変化します。敵に囲まれた場面でも、止まった時間の中を駆け抜けて斬り込むことで、ピンチから反撃へ転じる楽しさがあります。

### 4. ステージごとの変化とボス戦

全4ラウンドを進むにつれて、ダンジョンの風景や出現する敵が変わります。最終ラウンドではボスが待ち受けており、それまでに獲得した武器や強化、ダッシュと時間停止を駆使して挑みます。
