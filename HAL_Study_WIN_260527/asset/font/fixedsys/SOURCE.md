# Fixedsys Excelsior

Source: https://github.com/kika/fixedsys

Release: v3.09.10 (`FSEX302.ttf`)

The upstream project releases the font into the public domain and, where a
public-domain dedication is unavailable, under CC0.

`FixedsysExcelsior_ascii_320x512.png` is the printable ASCII range rendered as
a 16 by 16 atlas. Each cell is 20 by 32 pixels and uses hard, non-antialiased
edges for point-filtered in-game rendering.
